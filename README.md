# Portafolio.

Este repositorio contiene proyectos desarrollados tanto en Python como en HTML como parte de mi aprendizaje en Ciencias Computacionales.

## Proyectos:

### Generador de contraseñas
Programa que permite generar contraseñas seguras según distintos criterios definidos por el usuario.

### Conexión a MySQL
Script en Python que se conecta a una base de datos y consulta información de alumnos.

### Generador de horarios automaticos
Aplicacion web que facilita y acelera el proceso de agendar un horario de materias universitarias al iniciar cada nuevo semestre, afreciendo una funcion de crear el horario de forma manual como una funcion para crear un horario de forma automatica segun tus preferencias.
